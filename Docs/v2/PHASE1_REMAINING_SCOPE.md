# Deal Room V2 — Phase 1 Remaining Scope

The following remain intentionally outside Phase 1 and are expected to be implemented as later V2 domains:

- full Accounts domain and canonical-account enforcement redesign
- archive/ban workflows
- Stakeholders redesign, transactional Decision Maker invariant, and full tag domain
- OEM attachment/redaction/Leadership CRUD domain
- RFX Google Drive context capture beyond the lifecycle seam
- authoritative POC architecture, request/execution/assignment/result workflows
- Negotiations domain
- Delivery Project aggregate and delivery-team/completion workflow
- Activities and Follow-ups expansion
- complete later-domain notification workflows

These are not Phase 1 failures. Phase 1 only requires the core lifecycle/authorization/value/closure foundation to expose clean extension points and contain no contradictions that would force later domains to reintroduce legacy state-machine behavior.
