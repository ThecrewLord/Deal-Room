# Deal Room Frontend

React/Vite frontend built around the supplied `src/` implementation.

## Run

```bash
cp .env.example .env
npm install
npm run dev
```

Open:

```text
http://localhost:5173
```

## Build

```bash
npm run build
```

The API base URL is configured centrally through:

```text
VITE_API_BASE_URL=http://localhost:5000/api
```
